normalize_time v1.0.0

将自然语言描述的时间（如“下周五”、“24年春节”）转换为标准化的绝对时间格式。

📥 输入参数定义 (Request)

参数名 类型 必填 默认值 完整说明 / 枚举值 (Enums)
content String Required - 自然语言描述的时间实体。
示例："下周五", "2024年春节"
granularity String Optional day
所需的时间粒度。
year month day hour minute second
time_category String Optional point
时间类型分类。
point (时间点) range (时间区间) seq (时间序列)
exchange String Optional SSE
用于对齐交易日历的交易所代码。
SSE (上海) SZSE (深圳) HKEX (香港) NASDAQ NYSE LSE (伦敦) TSE (东京) SGX (新加坡)

📤 输出参数定义 (Response)

参数名 类型 说明 枚举 / 示例
code Integer 业务状态码，标识请求处理结果。 200 400 422 500
data Object 包含标准化后的核心数据。
Structure:
  • times: Array<String> (ISO dates)
  • time_type: String
  • entity: String
