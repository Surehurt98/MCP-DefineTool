时间标准化 (normalize_time)

将自然语言描述的时间（如“下周五”、“24年春节”、“明天下午三点”）转换为标准化的绝对时间格式。支持自定义时间粒度、节假日识别以及交易所交易日历对齐。

💻 API 接口定义

输入参数 Request

参数名 类型 必填 默认值 说明
content String 是 - 自然语言描述的时间实体。
示例： "下周五", "2024年春节", "Q1 2025"
granularity String 否 day 时间粒度。
枚举值：
  • year, month, day
  • hour, minute, second
time_category String 否 point 时间种类。
枚举值：
  • point (时间点), range (区间), seq (序列)
utc String 否 UTC+8 时区设置。
exchange String 否 SSE 交易所代码（用于对齐交易日）。
枚举值： SSE, SZSE, HKEX, NASDAQ, NYSE, LSE, TSE, SGX

输出参数 Response

参数名 类型 必填 说明
code Integer 是 状态码：200 (成功), 400 (无效), 422 (未识别), 500 (错误)
message String 是 人类可读的响应消息。
data Object 是 数据载体，包含：
  • granularity (String, req)
  • entity (String, req): 原始文本
  • time_category (String, req)
  • utc (String, req)
  • exchange (String, req)
  • times (Array<String>, req): ISO时间列表
  • time_type (String, req): absolute, relative, holiday, cycle

🧪 测试用例 (Test Cases)

测试场景 输入 (Input) 预期输出 (Expected Output Data)
Happy Path
(标准日期)		 content: "2024-12-25"
granularity: "day" 		times: ["2024-12-25 00:00:00"]
time_type: "absolute"
Holiday
(节假日/区间)		 content: "Spring Festival 2024"
time_category: "range" 		times: ["2024-02-10 00:00:00", "2024-02-17 23:59:59"]
time_type: "holiday"
Edge Case
(相对时间)		 content: "Next Friday"
utc: "UTC+8" 		times: ["2025-12-19 00:00:00"] (假设当前是12日)
time_type: "relative"
Validation Error
(缺失内容)		 content: "" or null Code: 400
Message: "Content is required"

📜 JSON Schema 构造

Input Schema (LLM Request)

{
  "type": "object",
  "required": ["content"],
  "properties": {
    "content": { "type": "string" },
    "granularity": { 
      "type": "string", 
      "enum": ["year", "month", "day", "hour", "minute", "second"],
      "default": "day"
    },
    "time_category": {
      "type": "string", 
      "enum": ["point", "range", "seq"], 
      "default": "point"
    },
    "utc": { "type": "string", "default": "UTC+8" },
    "exchange": { 
      "type": "string", 
      "enum": ["SSE", "SZSE", "HKEX", "NASDAQ", "NYSE", "LSE", "TSE", "SGX"],
      "default": "SSE"
    }
  }
}

Output Schema (LLM Response)

{
  "type": "object",
  "required": ["code", "message", "data"],
  "properties": {
    "code": { "type": "integer" },
    "message": { "type": "string" },
    "data": {
      "type": "object",
      "required": ["times", "time_type", "entity"],
      "properties": {
        "granularity": { "type": "string" },
        "entity": { "type": "string" },
        "time_category": { "type": "string" },
        "utc": { "type": "string" },
        "exchange": { "type": "string" },
        "times": { "type": "array", "items": { "type": "string" } },
        "time_type": { 
          "type": "string",
          "enum": ["absolute", "relative", "holiday", "cycle"]
        }
      }
    }
  }
}
