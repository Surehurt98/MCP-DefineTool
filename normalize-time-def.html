时间标准化 (normalize_time)

将自然语言描述的时间（如“下周五”、“24年春节”、“明天下午三点”）转换为标准化的绝对时间格式。支持自定义时间粒度、节假日识别以及交易所交易日历对齐。

💻 API 接口定义

输入参数 Request

参数名 类型 必填 默认值 说明 / 枚举值 (Enums)
content String 是 - 自然语言描述的时间实体。
示例： "下周五", "2024年春节", "Q1 2025"
granularity String 否 day 时间粒度，精确程度。
所有枚举值：
  • year (年)
  • month (月)
  • day (日)
  • hour (时)
  • minute (分)
  • second (秒)
time_category String 否 point 时间种类分类。
所有枚举值：
  • point: 时间点 (如 "今天")
  • range: 时间区间 (如 "五一假期", "1月到3月")
  • seq: 时间序列 (如 "每周一", "每月1号")
utc String 否 UTC+8 时区设置，用于计算相对时间。默认为中国标准时间。
exchange String 否 SSE 交易所代码（用于对齐交易日历）。
所有枚举值：
  • SSE (Shanghai Stock Exchange - 上海)
  • SZSE (Shenzhen Stock Exchange - 深圳)
  • HKEX (Hong Kong Stock Exchange - 香港)
  • NASDAQ (Nasdaq Stock Market - 纳斯达克)
  • NYSE (New York Stock Exchange - 纽交所)
  • LSE (London Stock Exchange - 伦敦)
  • TSE (Tokyo Stock Exchange - 东京)
  • SGX (Singapore Exchange - 新加坡)

输出参数 Response

参数名 类型 必填 说明 / 结构详情
code Integer 是 状态码。
  • 200: 成功 (Success)
  • 400: 请求参数无效 (Invalid Request)
  • 422: 语义无法识别/未知节假日 (Unprocessable Entity)
  • 500: 内部服务错误 (Internal Server Error)
message String 是 状态描述信息。
data Object 是 核心数据对象。
包含以下必填字段：
  • granularity (String): 返回请求时的粒度。
  • entity (String): 识别到的原始时间文本。
  • time_category (String): 识别到的时间类别。
  • utc (String): 使用的时区。
  • exchange (String): 使用的交易所日历。
  • times (Array<String>): ISO 8601 标准时间字符串列表。
  • time_type (String): 时间类型标记。
    枚举: absolute (绝对), relative (相对), holiday (节假日), cycle (周期)

🧪 测试用例 (Test Cases)

测试场景 输入 (Input) 预期输出 (Expected Output)
Happy Path {"content": "2024-12-25", "granularity": "day"} {"times": ["2024-12-25 00:00:00"], "time_type": "absolute"}
Holiday (Range) {"content": "Spring Festival 2024", "time_category": "range"} {"times": ["2024-02-10...", "2024-02-17..."], "time_type": "holiday"}
Edge Case {"content": "Next Friday", "utc": "UTC+8"} {"times": ["..."], "time_type": "relative"} (Depends on Today)
Error Case {"content": ""} code: 400, message: "Content is required"
