normalize_time v1.0.0

将自然语言描述的时间（如“下周五”、“24年春节”）转换为标准化的绝对时间格式。

📥 输入参数 (Request)

参数名 类型 必填 默认值 枚举值 / 说明 (Tag 可编辑)
content String Required - 自然语言描述的时间实体。
示例："下周五", "2024年春节"
granularity String Optional day
所需的时间粒度。
year month day hour minute second +
time_category String Optional point
时间类型分类。
point (时间点) range (区间) seq (序列) +
exchange String Optional SSE
交易所代码 (Trading Calendar)。
SSE SZSE HKEX NASDAQ NYSE LSE + 
{
  "type": "object",
  "required": ["content"],
  "properties": {
    "content": { "type": "string" },
    "granularity": { 
      "enum": ["year", "month", "day", "hour", "minute", "second"],
      "default": "day"
    },
    ...
  }
}

📤 输出参数 (Response)

参数名 类型 说明 结构 / 示例
code Integer 业务状态码：200=成功，400=非法请求，500=内部错误。 200 4xx
data Object 核心数据包。
- times: 标准化时间数组 [ISO 8601]
- time_type: [absolute, relative, holiday] 		{"times": ["2024-01-01"], ...}

🧪 测试用例 (Test Cases)

场景 (Scenario) 输入 (Input) 预期输出 (Expected Data)
1. 标准日期 (Happy Path) {"content": "2024-12-25"} {"times": ["2024-12-25 00:00:00"], "time_type": "absolute"}
2. 节假日区间 (Holiday Range) {"content": "2024年春节", "time_category": "range"} {"times": ["2024-02-10 00:00:00", "2024-02-17 23:59:59"], "time_type": "holiday"}
3. 相对时间 (Relative) {"content": "下周五", "utc": "UTC+8"} {"times": ["(Current + Next Fri)"], "time_type": "relative"}
4. 交易日对齐 (Exchange) {"content": "Christmas 2024", "exchange": "NYSE"} {"times": [], "message": "Market Closed"}
5. 错误输入 (Error) {"content": ""} {"code": 400, "message": "Content is required"}
6. 模糊时间 (Fuzzy) {"content": "明年一季度"} {"times": ["2026-01-01", "2026-03-31"], "granularity": "day"}
