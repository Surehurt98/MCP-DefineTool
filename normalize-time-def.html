时间标准化 (normalize_time)

将自然语言描述的时间（如“下周五”、“24年春节”、“明天下午三点”）转换为标准化的绝对时间格式。支持自定义时间粒度、节假日识别以及交易所交易日历对齐。

💻 API 接口定义

输入参数 Request

参数名 类型 必填 默认值 说明
code>content String 是 - 自然语言描述的时间实体。
示例： "下周五", "2024年春节", "Q1 2025"
granularity String 否 day 时间粒度。
枚举值：
  • year: 年
  • month: 月
  • day: 日
  • hour: 小时
  • minute: 分
  • second: 秒
time_category String 否 point 时间种类。
枚举值：
  • point: 时间点 (如 "今天")
  • range: 时间区间 (如 "五一假期")
  • seq: 时间序列 (如 "每周一")
utc String 否 UTC+8 时区设置，用于计算相对时间（如“明天”）。
exchange String 否 SSE 交易所代码（用于对齐交易日）。
枚举值：
  • SSE: 上海证券交易所
  • SZSE: 深圳证券交易所
  • HKEX: 香港交易所
  • NASDAQ: 纳斯达克
  • NYSE: 纽约证券交易所
  • LSE: 伦敦证券交易所
  • TSE: 东京证券交易所
  • SGX: 新加坡交易所

输出参数 Response

参数名 类型 说明
code Integer 响应状态码。
  • 200: 成功
  • 400: 请求参数无效
  • 422: 无法识别的节假日或实体
  • 500: 内部错误
message String 人类可读的响应消息。
data Object 返回的数据主体。
结构：
  • entity (String): 识别到的原始文本
  • times (Array<String>): 标准化后的时间列表 (ISO格式)
  • time_type (String): 时间类型 [absolute, relative, holiday, cycle]
  • 以及请求中的 granularity, time_category, utc, exchange 回显
