watchlist_manager v1.0.0

Retrieve customer watchlist groups and constituent stocks. (自选股管理)

📥 输入参数 (Request)

参数名 类型 必填 默认值 枚举值 / 说明 (Tag 可编辑)
customer_id String Required - 客户唯一标识符 (User ID)。
示例: "cust_12345"
query_mode String Optional full
查询模式。
full (分组+股票) summary (仅分组名) single (指定分组) +
list_id String Optional - 指定自选股列表ID (当 query_mode=single 时必填)。
market_filter String Optional ALL
市场过滤器。
ALL CN (沪深) US (美股) HK (港股) + 
{
  "type": "object",
  "required": ["customer_id"],
  "properties": {
    "customer_id": { "type": "string" },
    "query_mode": { 
      "type": "string",
      "enum": ["full", "summary", "single"],
      "default": "full" 
    },
    "list_id": { "type": "string" },
    "market_filter": {
      "type": "string",
      "enum": ["ALL", "CN", "US", "HK"],
      "default": "ALL"
    }
  }
}

📤 输出参数 (Response)

参数名 类型 说明 结构 / 示例
code Integer 业务状态码：200=成功，400=参数错误，404=用户不存在。 200 4xx
data Object
  • total_groups: Integer
  • groups: Array<Group>
    • id, name
    • constituents: Array<Stock>
 {"groups": [{"name": "My Tech", "constituents": [...]}]}

🧪 测试用例 (Test Cases)

场景 (Scenario) 输入 (Input) 预期输出 (Expected Data)
1. 获取全部 (Happy Path) {"customer_id": "8888"} {"groups": [{"name": "默认分组", "constituents": [{"symbol": "AAPL", "market": "US"}]}]}
2. 仅看分组 (Summary) {"customer_id": "8888", "query_mode": "summary"} {"groups": [{"id": "g1", "name": "Favorites"}, {"id": "g2", "name": "Tech"}]} (No constituents)
3. 查询指定分组 (Single) {"customer_id": "8888", "query_mode": "single", "list_id": "g2"} {"groups": [{"id": "g2", "constituents": [...]}]}
4. 筛选美股 (Market Filter) {"customer_id": "8888", "market_filter": "US"} Returns only US stocks in constituents.
5. 空数据用户 (Empty) {"customer_id": "new_user"} {"total_groups": 0, "groups": []}
6. 缺失参数 (Error) {"query_mode": "full"} {"code": 400, "message": "customer_id is required"}
